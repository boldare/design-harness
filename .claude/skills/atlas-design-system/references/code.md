# Code

React 18, TypeScript, CSS Modules, Storybook 8. Read two existing components before writing one (for example `src/components/Switch` and `src/components/TextField`) and match them exactly.

## Files
- Component: `src/components/<Name>/<Name>.tsx`, `<Name>.module.css`, `<Name>.stories.tsx`, `index.ts`, and an export in `src/index.ts`.
- Screen: `src/screens/<Name>/` with the same files; mockup frame sizes live in the story, not in CSS.

## CSS
- Only `var(--…)` from `src/styles/tokens.css` (generated by `npm run tokens`; never edit it). Allowed literals: `0`, `100%`, `50%`, `none`, `transparent`, `1` for flex, `inherit`, `currentColor` and keywords.
- Focus: `:focus-visible { box-shadow: var(--shadow-focus); }`.
- Disabled: `opacity: var(--opacity-disabled)` on the root.
- Runtime values: a value the component computes from its props while it runs (a thumb position, a filled fraction) is set inline as a custom property named `--rt-<name>` and read in CSS with `var(--rt-<name>)`. It is not a token and never stands in for one. The Claude Design build allows the `--rt-` prefix and nothing else that is not a token.

## Stories
- `Default` with controls, and `States` that renders every state from the spec side by side, labelled, with realistic copy from the spec. Give `States` the parameter `docs: { source: { type: 'code' } }`, as the existing screens do; without it the story crashes in `npm run storybook`.
- The global theme toggle must switch the story; never hard-code a theme.

## Checks (all must pass before the report)
```
npm run tokens
npm run lint:tokens      # rejects raw values in component and screen CSS
npm run typecheck
npm run build-storybook
```

## A running Storybook
Someone may be showing `npm run storybook` while you work; it watches every file. The static build above does not prove what that server shows.
- Change files with the Edit or Write tool, never with a script that empties a file and writes it again (`open(p, 'w')`, `cat >`, `sed -i`): the server can read the file halfway, keep the parse error and stop showing every story.
- If the server is running (port 6006, or the one `npm run storybook` printed), finish with `curl -s -o /dev/null -w '%{http_code}' http://localhost:6006/index.json`. A 500 names the file it could not index: `touch` that file and fetch again. Report done only on a 200.
